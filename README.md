# JSP Servlet Login & Logout Application

A simple Java web application built using JSP, Servlets, HTML, and CSS to demonstrate user login, logout, session management, and profile functionality.

## 📌 Project Overview

This project demonstrates the basic implementation of authentication and session handling in a Java web application.

The application allows a user to:

- Login using a login form
- Validate login credentials
- Create and manage a user session
- Access the profile page after successful login
- Logout from the application
- Destroy the active session
- Redirect users between different pages

## 🚀 Features

- User Login
- User Logout
- Session Management
- Profile Page
- Servlet-based Request Handling
- JSP/HTML Web Pages
- Java Backend
- Simple and beginner-friendly project structure
